## Fait

- Projet PlatformIO `pong-esp32` créé pour la carte **Seeed Studio XIAO ESP32S3**.
- Programme **Blink** compilé et téléversé : la LED orange clignote à 1 Hz (checkpoint validé par l'enseignant).
- **Port série** : les messages envoyés par la carte s'affichent dans le moniteur série.
- **TelePlot** : essayé, ne fonctionne pas encore.

## Comment ça marche

### La chaîne de développement (toolchain)

```
main.cpp ──(compilation)──> firmware.bin ──(USB, upload)──> mémoire flash de l'ESP32-S3 ──> exécution
```

1. **VS Code** sert d'éditeur ; l'extension **PlatformIO** gère tout le reste.
2. PlatformIO lit `platformio.ini` pour savoir **quelle carte** (XIAO ESP32S3), **quelle plateforme** (espressif32) et **quel framework** (Arduino) utiliser, et télécharge le compilateur adapté.
3. Le code C++ est **compilé** en un fichier binaire pour le processeur de l'ESP32-S3.
4. Le binaire est **téléversé** par USB dans la mémoire flash de la carte. Au redémarrage, le microcontrôleur exécute ce programme tout seul, sans ordinateur.

### Un programme Arduino

- `setup()` s'exécute **une seule fois** au démarrage : on y configure les broches et le port série.
- `loop()` s'exécute **en boucle** à l'infini : c'est le comportement de la carte.

### La LED embarquée (logique active basse)

La LED orange est reliée entre le **3,3 V** et la broche `LED_BUILTIN`. Le courant ne passe que si la broche est à **0 V** :

| Broche | Tension | LED |
|---|---|---|
| `LOW` | 0 V | allumée |
| `HIGH` | 3,3 V | éteinte |

### Le port série

La carte envoie du texte à l'ordinateur par le câble USB avec `Serial.print()`. Les deux côtés doivent parler à la **même vitesse** (115 200 bauds) : `Serial.begin(115200)` dans le code et `monitor_speed = 115200` dans `platformio.ini`. Sinon, le moniteur affiche des caractères illisibles.

La XIAO ESP32S3 utilise l'**USB natif** de l'ESP32-S3 : pas de puce de conversion USB-série, donc **pas de driver** à installer.

## Comment on a fait

### 1. Créer le projet

PlatformIO → **New Project** : nom `pong-esp32`, carte *Seeed Studio XIAO ESP32S3*, framework *Arduino*. Puis dans `platformio.ini` :

```ini
[env:seeed_xiao_esp32s3]
platform = espressif32
board = seeed_xiao_esp32s3
framework = arduino
monitor_speed = 115200
```

### 2. Brancher la carte

Câble **USB-C data** (un câble de charge seule ne transmet pas de données). Sur macOS, la carte apparaît comme `/dev/cu.usbmodem…`.

### 3. Écrire le Blink

`src/main.cpp` :

```cpp
#include <Arduino.h>

void setup() {
  pinMode(LED_BUILTIN, OUTPUT);   // la broche de la LED est une sortie
}

void loop() {
  digitalWrite(LED_BUILTIN, LOW);   // LED allumée
  delay(500);                       // 500 ms
  digitalWrite(LED_BUILTIN, HIGH);  // LED éteinte
  delay(500);                       // 500 ms -> période 1 s = 1 Hz
}
```

### 4. Téléverser

Bouton **Upload** (→) dans la barre PlatformIO. Si l'upload échoue : maintenir **BOOT**, rebrancher le câble, relâcher **BOOT**, relancer l'upload, puis appuyer sur **RESET**.

### 5. Lire le port série

Ajout de `Serial.begin(115200);` dans `setup()` et d'un `Serial.println(...)` dans `loop()`, puis ouverture du **moniteur série** (icône prise dans la barre PlatformIO) : les messages de la carte s'affichent.

### 6. TelePlot

Extension TelePlot installée pour tracer des valeurs en temps réel : aucune courbe ne s'affiche pour l'instant.

## Pourquoi

- **Commencer par un programme minimal** : le Blink valide toute la chaîne (éditeur, compilation, flash, carte). Si un problème apparaît plus tard, on sait que la toolchain n'est pas en cause.
- **`LOW` pour allumer** : imposé par le câblage de la LED côté 3,3 V.
- **115 200 bauds** : vitesse standard, assez rapide pour afficher beaucoup de messages sans ralentir le programme.
