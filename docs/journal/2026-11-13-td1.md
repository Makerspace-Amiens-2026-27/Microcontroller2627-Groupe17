- **Port série** : les messages envoyés par la carte avec `Serial` s'affichent dans le moniteur série de PlatformIO.
- **TelePlot** (tracé de valeurs en temps réel) : essayé, mais n'a pas fonctionné.

```cpp
#include <Arduino.h>

void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_BUILTIN, LOW);   // LED allumée (logique active basse)
  delay(500);
  digitalWrite(LED_BUILTIN, HIGH);  // LED éteinte
  delay(500);
}
```

## Pourquoi

- **Programme minimal d'abord** : un blink valide toute la chaîne (éditeur, compilation, flash, carte). Si un problème apparaît plus tard, on sait que la toolchain n'est pas en cause.
- **`LOW` allume la LED** : elle est câblée côté 3,3 V, donc la broche doit tirer vers la masse pour que le courant passe.
- **`monitor_speed = 115200`** : doit être identique au `Serial.begin(115200)` du programme, sinon le moniteur affiche des caractères illisibles.
- **Pas de driver** : la XIAO ESP32S3 utilise l'USB natif de l'ESP32-S3.
- **Procédure de secours** si l'upload échoue : maintenir BOOT, rebrancher le câble, relâcher BOOT, relancer l'upload, puis appuyer sur RESET.
