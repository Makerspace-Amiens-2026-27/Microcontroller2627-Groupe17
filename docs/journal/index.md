# Journal de bord

Journal **commun** du binôme (groupe 17) : une page par séance, pendant les heures
prévues ou en dehors, nommée `AAAA-MM-JJ-sujet.md` pour rester dans l'ordre
chronologique. Chaque page suit le modèle `_modele-seance.md` : **Fait**,
**Comment ça marche**, **Comment on a fait**, **Pourquoi**, **Reste à faire**.
